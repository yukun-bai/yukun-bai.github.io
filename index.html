About me关于我

I am an M.Sc. student in Signal Processing and Machine Learning at the School of EEE, Nanyang Technological University (NTU), Singapore, working on embodied AI for robot manipulation. My research asks how a robot policy can see precisely (grounding-first VLA), learn quickly in the real world (sample-efficient online RL with human-in-the-loop), and remember what it has done (multi-timescale memory for long-horizon manipulation).

I have hands-on experience training and deploying policies on Franka FR3 and ARX X5 dual-arm robots, and co-authored a paper in IEEE RA-L 2026. Before NTU, I received my B.Eng. in Software Engineering from Dalian University of Technology.

我是南洋理工大学（NTU）电气与电子工程学院信号处理与机器学习硕士生，研究面向机器人操作的具身智能。 我关注三个问题：策略如何看得准（视觉定位优先的 VLA）、如何在真机上学得快（人机协同的高样本效率在线强化学习）、 以及如何记得住（面向长时程操作的多时间尺度记忆）。

有 Franka FR3 与 ARX X5 双臂真机上的策略训练与部署经验，参与的工作发表于 IEEE RA-L 2026。本科毕业于大连理工大学软件工程专业。

Research interests研究方向

  • Grounding-first VLA视觉定位优先的 VLA

    Point at the target first, then act: visual reference tokens, boxes and masks that condition a flow-matching action head. 先指出目标再生成动作：用视觉引用 token、框与掩码条件化 Flow-Matching 动作头。

  • Real-world online RL真机在线强化学习

    Sample-efficient, human-in-the-loop RL on real robots, with better credit assignment under sparse rewards. 真机上的人机协同、高样本效率 RL，改善稀疏奖励下的信用分配。

  • Embodied memory具身记忆

    Short-term visual history and event-level long-term memory so policies notice failures and avoid repeating them. 短时视觉历史与事件级长时记忆，让策略感知失败、避免重复犯错。

  • Robot agentsRobot Agent

    Coding agents that explore with perception and planning tools and distill successes into reusable closed-loop programs. 借助感知与规划工具在线探索的 Coding Agent，把成功策略沉淀为可复用的闭环程序。

Looking ahead后续研究计划

Autonomous exploration and continual learning for robot agents: integrating 3D perception, geometric modeling, motion planning and robot control as MCP tools; letting a coding agent explore online, analyze execution feedback and turn successful strategies into reusable closed-loop programs; and studying experience-memory management, cross-task skill transfer and multi-agent parallel exploration, evaluated on simulation benchmarks such as DexJoCo and RoboDojo.

面向 Robot Agent 的自主探索与持续学习：通过 MCP Tools 集成三维感知、几何建模、运动规划与机器人控制；利用 Coding Agent 在线探索、分析执行反馈，并将成功策略转化为可复用的闭环程序。 进一步研究经验记忆管理、跨任务技能迁移与多 Agent 并行探索，拟在 DexJoCo、RoboDojo 等仿真基准上评估任务成功率、探索效率及跨场景泛化能力。
